Engine Architecture

Engineered for deterministic safety.

Three-stage trait pipeline combining memory-safe Rust execution, bounded DoS budgets, and dual Apache-2.0 or MIT licensing.

01

ContentProcessor (Stage 1)

Extracts YAML 1.2 frontmatter via noyalib, parses CommonMark + GFM tables, footnotes, and strikethrough via pulldown-cmark, generates semantic TOC navigation, and enforces an explicit HTML tag allowlist.

02

HandlebarsRenderer (Stage 2)

Compiles and caches .hbs templates in a thread-safe parking_lot::RwLock registry. Supports nested partials, custom TemplateHelper implementations, balanced-brace checks, and strict variable validation.

03

HtmlGenerator (Stage 3)

Verifies HTML5 structural tag balance across void and optional-close elements, injects escaped meta tags into head, minifies HTML/CSS/JS in ~8.1 µs via minify-html, and manages static asset caching.

Frequently Asked Questions

Can I use NucleusFlow as a Rust library as well as a CLI binary?

Yes. Unlike monolithic static site binaries such as Hugo or Zola, NucleusFlow is published on Crates.io as both a library crate (nucleusflow) and a standalone CLI binary. You can embed ContentProcessor, HandlebarsRenderer, HtmlGenerator, or the NucleusFlow orchestrator directly inside your Rust services.

Which Markdown, frontmatter, and template formats are supported?

NucleusFlow parses CommonMark plus GitHub Flavored Markdown (tables, footnotes, strikethrough) via pulldown-cmark 0.13.5, extracts YAML 1.2 frontmatter via noyalib 0.0.58, compiles Handlebars (.hbs) templates via handlebars 6.2, and minifies HTML5 via minify-html 0.18.1.

What is the Minimum Supported Rust Version (MSRV)?

NucleusFlow requires Rust 1.89.0 or newer (2021 Edition). This floor is enforced at compile time via Cargo.toml and build.rs and verified in CI.

Is NucleusFlow open source and available for commercial use?

Yes. NucleusFlow is dual-licensed under the Apache-2.0 and MIT open-source licenses, allowing commercial and open-source embedding without copyleft restrictions.
