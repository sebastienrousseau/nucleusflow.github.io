## Thank You &amp; Ecosystem Acknowledgements

First, if you have just submitted an inquiry through our [Contact](/contact/index.html) form, **thank you for reaching out**; we review every message and will respond shortly.

We also extend our gratitude to the open-source maintainers whose Rust crates and web standards make **NucleusFlow** and **`nucleusflow.com`** possible:

| Project / Crate | Version | Role in NucleusFlow |
| :--- | :--- | :--- |
| **`pulldown-cmark`** | `0.13.5` | CommonMark and GitHub Flavored Markdown (GFM) pull parser |
| **`noyalib`** | `0.0.58` | Memory-safe YAML 1.2 frontmatter extraction and validation |
| **`handlebars`** | `6.2` | Handlebars (`.hbs`) template compilation, partials, and helpers |
| **`minify-html`** | `0.18.1` | High-speed HTML5, CSS, and JavaScript minification |
| **`parking_lot`** | `0.13` | Compact, low-overhead `RwLock` synchronization primitives |
| **`clap`** | `4.5` | Command-line interface parsing and help generation |
| **`serde` &amp; `toml`** | `1.0` / `0.9.5` | Structured configuration and JSON-LD serialization |
| **`thiserror`** | `2.0` | Ergonomic `ProcessingError` and `ProcessError` definitions |
| **`ssg` &amp; `Skeletonic CSS`** | `0.0.69` | Static site compiler and WCAG 2.2 AAA CSS foundation powering `nucleusflow.com` |
