## Highlights ⭐️

* **The first public site**: We published nucleusflow.com, the documentation site for the NucleusFlow Rust static site generator and content processing pipeline, built with the Static Site Generator (ssg) and served by GitHub Pages.
* **Start here**: The site introduces the three-stage pipeline (MarkdownProcessor, HandlebarsRenderer, HtmlGenerator), documents the CLI and Rust library API, presents Criterion benchmarks (~28.0 µs per page), and links to its source and dual Apache-2.0 OR MIT licence.
